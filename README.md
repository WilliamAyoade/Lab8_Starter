https://williamayoade.github.io/Lab8_Starter/ 


Graceful degradation and service workers are related as graceful degradation can have us start with a fully working web technology, and then use service workers to handle lower level concerns in the background gracefully during unideal situations. Service workers can handle things like poor internet connection, or user environments with limited capabilities. This allows us to address things like resilience, after the upper level of the technology is handled separately.
